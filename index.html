设置

所有设置保存在本机浏览器，不会上传。

音名与音域

音名体系 默认按小字组显示：中央C = c1。可切换成你习惯的写法。
显示键盘提示条 在琴键下方显示对应的电脑键盘字母。

音准

A4 校准 标准 440Hz；如果你的钢琴/乐器略高或略低，可以微调。

试听与自检 用调音器测一下 A4，或听一遍 C 大调音阶。

难度

当前模式 新手：慢速、幽灵手开、键盘提示开。

导入

本地文件只在这个浏览器里处理，不会上传到任何服务器。

选择或拖入音频文件 mp3 / wav / m4a / ogg / flac · 最大 25MB

导入后可在页面底部播放伴奏，边听边弹；不会写入磁盘，也不会随页面刷新保留。

选择或拖入 .mid / .midi 文件 默认提取主旋律轨，生成可练习的下落音符

当前演奏模式是单旋律 + 和声；复音 MIDI 默认提取最高平均音高的轨道。最大 512KB / 2000 个音符。

选择或拖入一段独奏/清唱音频 浏览器内 AI 扒谱，生成可练习旋律 · 建议 60 秒以内

基于 Spotify Basic Pitch（Apache-2.0）。识别对独奏/清唱较好，复杂混音会不准；只提取主旋律。首次使用需要加载约 1MB 模型。
