关于落音 PianoFall

零基础也能弹一首像样的曲子。一个纯前端、零框架的在线钢琴与练习工具。

落音最初只是想解决一个很小的问题：想随手弹一段，但不想装软件、不想注册、不想等加载。于是就做成了一个打开网页就能弹的钢琴。

它能做什么

  • 三个八度键床，鼠标、触摸、电脑键盘都能弹，支持刮奏与延音。
  • 95 首公有领域曲目：儿歌、中国民歌、古典主题、完整曲、圣诞颂歌、世界民谣。
  • 新手 / 高手双模式：慢速 + 宽判定 + 幽灵手补音，或原速 + 严格判定。
  • 本地音频伴奏：导入 mp3 / wav / m4a / ogg / flac，播放、循环、调速、音量都在浏览器内完成。
  • MIDI 导入与浏览器内智能扒谱（Spotify Basic Pitch），把旋律变成可练习谱。
  • 可安装为 PWA，二次打开离线可用。

怎么做的

纯 HTML / CSS / JavaScript，没有构建步骤，没有后端；音频与扒谱都在浏览器本地处理。曲库里的古典曲目为项目简化编配或主题片段，完整曲来自公有领域 MIDI；具体来源写在页脚和 README。
